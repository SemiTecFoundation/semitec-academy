# Introducing SemiTec Academy

Open `index.html` in a modern browser to present the product locally. It is a self-contained HTML/CSS/JavaScript deck: no network access, build step or presentation software is needed.

The deck covers the catalog, package verification, the library and study plan, trainings and quizzes, labs and projects, optional certificates, and the publisher workflow. The `assets/` directory contains selected Academy interface screenshots used in the slides.

Controls: **Left/Right**, **Space**, **Home**, **End**, or the buttons at the bottom. Press **F** for fullscreen.
