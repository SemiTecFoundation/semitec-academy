One clear path

From a publisher’s package to a learner’s achievement.

Packages can contain trainings, readings, labs, videos, materials and projects. A learner can use every item independently, or follow the author’s course order and study plan.

  1. 01PublishCreate and share an .stlp package.
  2. 02DiscoverBrowse a catalog or receive a package file.
  3. 03AddAcademy verifies and installs it locally.
  4. 04LearnComplete trainings, labs and projects.
  5. 05RecogniseReceive optional certificates when defined.
⌁

Local by design. Academy keeps accounts, packages and progress on the learner’s computer. A future platform can add organisation-wide sign-in and synchronization.

01 · Find materials

A catalog makes packages easy to discover.

Universities, companies and the Foundation can publish catalog links. Learners choose a source, then search and filter packages by publisher, subject and content type.

  • Compare package descriptions before adding them.
  • See the publisher, version and included content.
  • Install from a catalog, a local folder, or a shared .stlp file.

Built in: the SemiTec Foundation catalog is set up in every Academy app. Each package the Foundation publishes in SemiTec Academy Materials appears there automatically, with no app update; new versions show as updates.

02 · Add with confidence

A package carries its content and course plan together.

Academy checks the archive before it is added. It tells the learner what the package contains, which app version it needs, and the publisher details included by the author.

04 · Learn actively

Trainings combine explanation, interaction and progress.

Authors can create standard Academy trainings or flexible HTML, CSS and JavaScript experiences. Both forms can record progress and include quizzes when the author chooses.

  • Topics open in a structured course sequence.
  • Quizzes can unlock a next topic after a chosen passing score.
  • Progress is saved for the learner’s normal study view.

A password-protected author preview can open all sections for review without changing learner progress.

05 · Apply knowledge

Labs and projects turn learning into practical work.

A lab can bring together its manual, source code, links and materials. A project works in the same way for a larger brief, while remaining a separately tracked activity.

  • Manual steps let learners mark real work complete.
  • Code, assets and attachments stay with the item.
  • One download gives the learner the full item folder.

The author may include feedback contact details, but Academy does not require supervision or an external approval process.

06 · Recognise achievement

Certificates are optional, publisher-defined and personal.

A publisher can include a certificate for an individual training and/or for the whole package. If they do not define one, learners can still complete and use every item.

1Author chooses whether a training or package offers a certificate.

2Academy checks completion using real learning progress, including manual steps where required.

3Learner saves or prints the optional certificate created from the publisher’s HTML design.

For universities

Free for your students. Ready for a class today.

SemiTec Academy is open source under Apache-2.0. Students use it on their own computers; there is no server to run, no licence fee and no sign-up with the Foundation.

  1. 01DownloadEach student installs the app for Windows, macOS or Linux from the latest release.
  2. 02Create an accountA local username and password; progress stays in a folder the student chooses.
  3. 03Add a packageInstall from the built-in SemiTec Foundation catalog, where new Foundation packages appear automatically, or drop in a .stlp file you share.
  4. 04StudyFollow the course order or study plan; resume where you left off.
  5. 05Publish your ownLecturers can create packages and a catalog with the Academy Templates, no approval needed.
⌁

Open and reviewable. The app, its package format and its tests are public on GitHub. Questions and feedback: open an issue or write to info@semitec.org.
