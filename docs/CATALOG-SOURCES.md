# Foundation-recommended catalog sources

The SemiTec Foundation maintains this catalog of its published materials:

```text
https://semitecfoundation.github.io/semitec-academy-materials/catalog/catalog.json
```

Its source repository is [SemiTec Academy Materials](https://github.com/SemiTecFoundation/semitec-academy-materials).
Academy adds the catalog as an initial source when no source settings exist. To add it again, copy the
URL above and select **Settings → Application → Catalog sources → Add a catalog link**. Existing source
settings are preserved; users may remove this source or add other companies' catalog links and local folders.
Use the direct `catalog.json` URL, not the GitHub repository page.

The Foundation maintains the source list; a catalog and a publisher name do not cryptographically prove
the origin of an individual download. Academy checks package structure, paths and content hashes before
installation. Anyone may distribute packages directly or through their own catalog.
