# stlp — the pack builder

`node packer/stlp.js <command>` — run `npm install` in `../app` once (it shares the code that verifies
packs in the app). Commands: `init`, `add-training`, `add-reading`, `add-lab`, `validate`, `build`,
`inspect`, `keygen`; `node packer/stlp.js` without arguments prints the usage.
Guide: `../docs/AUTHORING.md`. Format: `../docs/PACKAGE-FORMAT.md`.
